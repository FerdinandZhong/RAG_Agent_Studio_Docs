# RAG & Agent Studios

Welcome to the documentation site for RAG & Agent Studios - a comprehensive platform for building production-ready AI chatbots powered by Retrieval-Augmented Generation (RAG).

## Overview

RAG & Agent Studios provides enterprise-grade tools for creating intelligent chatbots that understand and respond to queries based on your own data. Whether you're a non-technical user looking to build a quick prototype or an ML team deploying at scale, our platform offers the flexibility, speed, and intelligence you need.

## Key Features

- **Easy Knowledge Base Creation** - Upload documents and configure indexing with just a few clicks
- **Advanced RAG Techniques** - Built-in support for HyDE, O-RAG, and Metadata-Augmented RAG
- **Flexible Model Integration** - Connect with OpenAI, Azure OpenAI, AWS Bedrock, or CAII
- **Real-time Analytics** - Monitor performance with built-in metrics and HITL capabilities
- **Enterprise Ready** - Support for external databases, S3 storage, and secure deployments
